# Precise Glower

English | [简体中文](README.md)

A Minecraft Fabric client mod that draws highlight outlines or glows around blocks, entities and
dropped items, with a lot of per-rule configuration.

![Screenshot](展示.jpg)

## Usage

Press **`G`** to open the screen.

![Example](示例.jpg)

## Features

- **Block highlighting**: highlight chosen blocks, filterable by ID, tag and block state; initial
  colours are assigned automatically; the outline skips faces shared with neighbours, and an
  entity-style glow is available
- **Entity highlighting**: highlight chosen entities, filterable by ID and NBT; hitbox highlighting
  is supported
- **Item highlighting**: highlight chosen dropped items, filterable by ID and stack size
- **Entity hiding**: adjust the opacity of chosen mobs, ignore interaction with chosen entities,
  and hide chosen dropped items
- **Search**: search by ID or by name
- **Completion**: autocomplete for IDs, block states and NBT
- **Shape**: outline colour and width, plus highlight range
- **Wildcards**: match purely by block state or entity NBT
